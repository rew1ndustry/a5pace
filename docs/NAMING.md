# Names

The project is **a5pace**, published as `rew1ndustry/a5pace`: the namespace is chosen to be unique, and the repository name
says the same thing as the tools do. The program that runs a session is `a5pace`; the thing it keeps is "aspace" (a space)
in prose.

## The rule for tool names

Every tool and utility starts with `a5`.

- If the rest of the name **begins with an `s`**, the `5` stands for that capital S in "leet" spelling: `a5pace` reads
  *a-S-pace* (the `5` is the S of "space"). So a tool for something starting with s keeps its `s` inside the `5`:
  `a5pace` (space), `a5hell` (shell), and so on. The `5` is the capital S; no second `s` is written.
- Any tool whose name does **not** begin with an `s` is simply `a5` followed by the name: `a5card`, `a5click`, `a5control`,
  `a5create`, `a5cal`, `a5doctor`, `a5export`, `a5import`, `a5tune`, `a5start`, `a5play`.

The rule is applied even where it reads badly, on purpose, because a convention with exceptions is not one. For a shell it gives
`a5hell`, which looks wrong with that ending; but `a5shell` is worse, because the `5` is an S and it then reads "ass hell". So the
terminal shell is **`a5hell`** (it was called a5shell until 2026-10-29; `make install` puts a5hell in place, and an old a5shell
left in a bin directory can be removed by hand). A new tool follows the rule and does not invent another pattern.
